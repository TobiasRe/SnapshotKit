# Keyboard shortcuts

## Projects and windows

| Shortcut | Action |
|---|---|
| ⌘K | Go to a project or run a command (the palette) |
| ⌘O | Add a project |
| ⇧⌘O | Import a result bundle (`.xcresult`, e.g. a CI artifact) |
| ⌘, | Settings |
| ⌥⌘1 | Snapshots tab |
| ⌥⌘2 | Changes tab |
| ⌥⌘3 | Failures tab |
| ⌥⌘4 | Run tab |
| ⌘F | Filter the current list (Escape clears the filter, a second Escape leaves the field) |

## Running and recording

| Shortcut | Action |
|---|---|
| ⌘R | Run the snapshot tests |
| ⌃⌘R | Run on the remote machine |
| ⇧⌘R | Re-record the selected test (snapshot, change or failure), then verify |
| ⌥⇧⌘R | Re-record all failing tests, then verify |
| ⌥⌘R | Check flakiness of the failing tests |
| ⌘. | Cancel the run |
| ⌥⌘O | Open the selected snapshot's test in Xcode, at its function |

## Lists

| Shortcut | Action |
|---|---|
| ↑ / ↓ | Previous / next item in the focused list |
| ⌥⌘↑ / ⌥⌘↓ | Previous / next change or failure, wherever the focus is |
| V (in the Changes list), ⌥⌘V | Mark the selected change as viewed and go to the next one |
| Space | Quick Look the selected snapshot |
| ⌘C | Copy the selected snapshot's image |

## Comparing

| Shortcut | Action |
|---|---|
| ⌘1 | Side by side |
| ⌘2 | Slider |
| ⌘3 | Difference |
| ⌘4 | Toggle |
| Space | Flip between the images (in Toggle mode) |
| ← / → | Move the slider divider (in Slider mode) |
| ⌘= / ⌘− | Zoom in / out |
| ⌘0 | Fit (also: double-click the image) |
| ⇧⌘0 | Zoom to the changed pixels |

Trackpad: pinch to zoom, two-finger drag to pan. Mouse: drag to pan.

## The palette (⌘K)

| Key | Action |
|---|---|
| type | filter projects and commands |
| ↑ / ↓ | move the highlight |
| Return | open the project or run the command |
| Escape | close |
