Companion app for swift-snapshot-testing

Review and re-run every snapshot test in one app.

Your tests already record reference images with swift-snapshot-testing. SnapshotKit is the Mac app, menu bar item and command-line tool that works with them: browse every image, review what your branch changed, run the tests like CI and re-record what should change. Nothing to add to your project.

Free and open source (MIT) · macOS 14 or later · Apple silicon

How it fits in

  1. 1

    You test with swift-snapshot-testing

    Your iOS or macOS project already has snapshot tests, with Swift Testing or XCTest.

    @Test func payButton() {
  assertSnapshot(of: PayButton(),
                 as: .image)
}
  2. 2

    They record reference images

    Each test writes PNGs next to it, in a __Snapshots__ folder in your repository.

    CheckoutTests/
  __Snapshots__/CheckoutTests/
    payButton.light.png
    payButton.dark.png
  3. 3

    SnapshotKit works with them

    Open the repository. SnapshotKit finds the images, reads how CI runs the tests, and lets you review, run and re-record them.

    • No dependency to add, no code to change
    • Reads your CI configuration and test results
    • Re-records by switching record mode on and off for you

New to snapshot testing? Start with Point-Free's swift-snapshot-testing, then point SnapshotKit at your project.

See the CLI
Review

Review snapshots like code.

Every PNG that differs from the base branch, committed or not, against the merge-base or the branch tip. Each change names the commit that last touched it.

Failures

Know why it failed.

Reference, actual and difference for the last run or an .xcresult from CI. Each difference is diagnosed, flaky tests are named, and every test shows its recent runs.

Diagnosis

Invisible differences, explained.

When a test fails on another machine without a visible change, SnapshotKit says so and offers the precision that would pass.

Update

Re-record what should change.

One test, a suite, every dark variant you filtered to, the failing ones or all of them, run the way CI runs them. The record trait is restored even if you quit, and the new references are verified.

Menu bar

Your test runs, one glance away.

Turn on Show in menu bar and SnapshotKit keeps an eye on your projects while you work in Xcode.

  • A pie fills as tests complete, with a done/total count, and shows the failing count when nothing runs.
  • Live progress for every running project, passed and failed so far, the test running now, and Cancel.
  • Your failing, pinned and recent projects, to open or run in one click.
  • Close the window and it keeps running. The Dock icon shows the failing count too.

snapshotsList every snapshot with its state; find orphans; sort by size or recency.
changesSnapshots that differ from the base branch, at the merge-base or the tip.
recordRe-record the tests of the snapshots whose path contains every word you give.
runRun the snapshot tests the way CI does, locally or on a remote Mac.
rerecordRe-record the failing suites of the last run, then verify.
failuresList failures from the last run or an .xcresult and diagnose each one.
flakyRun the failing tests several times and say which are flaky.
historyRecent runs and flaky tests, for the project or one test.
diffPixel and perceptual difference of two PNGs, with a precision that passes.
openThe same, then compare the two in SnapshotKit: your diff tool for failing tests.
configThe configuration CI uses, with a check of Xcode and the simulator.
restoreUndo a record patch left behind by an interrupted run.
projectsScan folders for repositories with snapshot tests, or list them.

Your diff tool, too.

Name snapkit open as swift-snapshot-testing's diff tool, and every failing test's message ends in a command that opens the reference and the actual image side by side in SnapshotKit, one click from the snapshot in its project.

extension SnapshotTestingConfiguration.DiffTool {
  static let snapkit = Self {
    "snapkit open \"\($0)\" \"\($1)\""
  }
}

// Swift Testing
@Suite(.snapshots(diffTool: .snapkit))

// XCTest
withSnapshotTesting(diffTool: .snapkit) { … }

Install

Download the app and the CLI from the latest release, for Apple silicon and macOS 14 or later. Unzip and move SnapshotKit.app to Applications.

Download for Mac

First launch

The app is ad-hoc signed and not notarized. Choose Open Anyway in System Settings › Privacy & Security, or run:

xattr -dr com.apple.quarantine \
  /Applications/SnapshotKit.app

From source

With Xcode 26 or later, this builds the app and the CLI into ./dist.

git clone https://github.com/TobiasRe/SnapshotKit
cd SnapshotKit
scripts/make-app.sh
